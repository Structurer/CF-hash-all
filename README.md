# CF-hash-all

纯前端的本地哈希计算工具。所有计算在浏览器本地完成，数据不会上传至任何服务器，适合对隐私敏感的文本与文件校验场景。可直接作为静态站点部署到 Cloudflare Pages / GitHub Pages 等。

## 功能特性

- **文本实时计算**：输入即算，无需点击按钮
- **文件拖拽计算**：支持单文件、多文件、文件夹递归遍历
- **多算法并行**：一次输入同时输出多种算法的哈希值
- **一键复制**：点击哈希值或复制按钮即可复制到剪贴板
- **响应式设计**：适配桌面与移动端
- **纯本地运行**：无后端、无网络请求、无数据上传

## 支持的哈希算法

共支持 10 种算法，可任意组合勾选：

| 分组 | 算法 | 默认勾选 |
| --- | --- | --- |
| MD5 | MD5 | ✓ |
| SHA-1 | SHA-1 | |
| SHA-2 | SHA-256、SHA-384、SHA-512 | SHA-256、SHA-512 |
| SHA-3 | SHA3-224、SHA3-256、SHA3-384、SHA3-512 | |
| 其他 | RIPEMD-160 | |

## 技术栈

- 原生 HTML / CSS / JavaScript（无框架、无构建工具）
- [CryptoJS](https://github.com/brix/crypto-js) —— 哈希算法实现
- Google Fonts（Inter）

## 使用方式

### 本地预览

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

或在项目目录启动一个静态服务器：

```bash
# Python 3
python -m http.server 8000

# Node.js（需全局安装 http-server）
http-server -p 8000
```

然后访问 `http://localhost:8000`。

### 部署到 Cloudflare Pages

1. 将仓库推送到 GitHub / GitLab
2. 在 Cloudflare Pages 控制台连接该仓库
3. 构建命令留空，输出目录填 `/`（根目录）
4. 保存并部署

### 部署到 GitHub Pages

1. 将仓库推送到 GitHub
2. 在仓库 Settings → Pages 中选择分支与根目录
3. 保存后通过 `https://<用户名>.github.io/<仓库名>/` 访问

## 使用说明

- **计算文本哈希**：在输入框中直接输入文字，结果区会实时刷新
- **计算文件哈希**：将文件或文件夹拖入输入框，工具会自动递归读取并逐个计算
- **切换算法**：勾选/取消顶部的算法选项，已有结果会自动重新计算
- **复制结果**：点击哈希值文本或其左侧的复制按钮均可复制
- **清空**：点击结果区右上角的"清空"按钮可清空所有输入与结果

## 隐私说明

所有哈希计算均在浏览器本地通过 CryptoJS 完成，不会向任何服务器发送输入文本或文件内容。页面仅加载静态资源（HTML/CSS/JS/字体），无任何数据上报。
